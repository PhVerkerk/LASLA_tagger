Le dossier **Tagueur_IA** contient les données nécessaires
à Collatinus et au tagueur HMM3.
Il va recevoir les exécutables créés par la compilation des codes sources,
avec toutes les dll nécessaires si on a demandé le déploiement.

Il devrait aussi contenir l'exécutable simple_pred.exe
obtenu par compilation à l'aide de PyInstaller
du code Python simple_pred.py. Toutefois, cet exécutable
est trop volumineux pour être téléchargé ici.
Cet exécutable permet de s'affranchir de l'environnement Python (instable)
et utilise les modèles obtenus avec Latin_BERT sur le 
corpus du LASLA.
Ces modèles sont aussi trop volumineux pour être déposés ici.
